# dental-web

Landing page for a dental clinic, built with plain HTML, CSS and JavaScript. There is no build step.

Open `index.html` in a browser to view it.

## Before launch
- Set the clinic name, WhatsApp number and phone number in `js/main.js` (`CONFIG`).
- Replace the `[[PLACEHOLDERS]]` in `index.html`.
- Add `images/hero.jpg` and replace `images/doctor.svg` with a real photo.
- Replace the Google Maps embed `src` with your clinic's location.

See `plan.md` for the full plan.
